# SegmentedControl

Escolha exclusiva entre 2–5 opções curtas e sempre visíveis; o consumidor fornece os rótulos e o valor atual.

- Usos: estratégia de layout do container (Grade · Pilha · Livre · Abas), densidade, Visual | Geral, Visual | BEL.
- Segmentos de `control-sm` dentro de um trilho de 28 px em `surface-pressed`; o ativo vira `surface-panel` com peso 600.
- Mais de 5 opções ou rótulos longos: use Select.
