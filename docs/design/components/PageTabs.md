# PageTabs

Abas das páginas do dashboard no rodapé do canvas (36 px); o consumidor fornece as páginas, a ativa e a ação de nova página.

- Ativa sobe para `surface-panel` com filete de 2 px em `accent` no topo.
- Duplo clique renomeia; arrastar reordena; menu de contexto: duplicar, ocultar, excluir.
- Não confundir com Tabs (vistas de painel) nem com o container `tabs` dentro da página.
