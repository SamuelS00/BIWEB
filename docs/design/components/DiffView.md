# DiffView

Comparação entre revisões de um dashboard ou modelo; o consumidor fornece as duas versões e a lista de mudanças por objeto.

- Mesma linguagem do preview de IA: `+` adição (`accent`), `~` alteração (`warning`), `−` remoção (`danger`); valor antigo riscado em `danger`, novo destacado em `accent-subtle`.
- Duas vistas: Lista e No canvas (fantasmas, destaque de remoção e handles de diff sobre o runtime).
- Ações: Restaurar (rollback cria nova revisão) e Publicar.
