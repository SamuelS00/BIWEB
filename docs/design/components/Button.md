# Button

Botão de texto para ações explícitas; o consumidor fornece o rótulo (verbo no infinitivo) e, opcionalmente, um ícone de 16 px à esquerda.

- Variantes: `bw-btn--primary` (uma por região: Aplicar, Publicar), padrão (secundário), `bw-btn--ghost` (ações de baixa ênfase em toolbars), `bw-btn--danger` (destrutivo, sempre com confirmação).
- Tamanhos: padrão `control-md` (28), `bw-btn--lg` `control-lg` (32) só na barra superior e em Cancelar/Aplicar de propostas, `bw-btn--sm` `control-sm` (24) em rodapés de widget e linhas densas.
- Desabilitado com `disabled` + `title`/tooltip explicando o motivo. Nunca esconda o botão.
- Não use ícone sozinho aqui: para isso, IconButton.
