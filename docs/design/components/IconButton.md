# IconButton

Botão só com ícone para ações frequentes e reconhecíveis; o consumidor fornece o ícone de 16 px e um `aria-label` que também vira tooltip.

- Área de 28×28 (`control-md`) ou 24×24 (`bw-iconbtn--sm`, mínimo WCAG 2.2). O glifo é sempre `icon-md`.
- `aria-pressed="true"` para alternâncias (snap, régua, grade), pintado em `accent-subtle` + `accent`.
- Toda toolbar de IconButtons oferece "Mostrar rótulos" no menu de contexto.
