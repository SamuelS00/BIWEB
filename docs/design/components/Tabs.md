# Tabs

Abas sublinhadas para alternar vistas dentro de um painel; o consumidor fornece os rótulos, contadores opcionais e a aba ativa.

- Ativa = texto `text-primary` 600 + sublinhado de 2 px em `accent`. Sem fundo, sem cápsula.
- Use no máximo 4 abas por painel (Dados · Formato · Filtros). Abas de páginas do dashboard são PageTabs, não Tabs.
