# Badge

Selo de estado curto ao lado de um nome; o consumidor fornece a palavra e, quando houver, o ícone.

- Tons: `success` (Certificado, Conectado), `warning` (Rascunho, Depreciado, PII, Não certificado), `danger` (Falha), neutro (Publicado v12), `accent` (Em uso).
- Sempre palavra ou ícone além da cor. Contador (`bw-counter`) para quantidades em abas e seções recolhidas.
