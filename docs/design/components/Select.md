# Select

Escolha de um valor numa lista que abre num Menu; o consumidor fornece opções, valor e placeholder.

- Mesma altura e borda de Input. Cor usa swatch de 14 px + nome (nunca só a cor).
- Para listas longas ou com busca (campos, métricas), use o Combobox do FieldPicker; para 2–5 opções curtas, SegmentedControl.
