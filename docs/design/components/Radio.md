# Radio

Escolha exclusiva entre opções com descrição ou rótulo longo; o consumidor fornece o grupo (com nome acessível), as opções e o valor.

- Círculo de 14 px, ponto `accent` quando marcado; a linha inteira (≥24 px) é clicável.
- Use em diálogos e no FilterBuilder. No Inspector, prefira SegmentedControl (opções curtas) ou Select (muitas opções).
