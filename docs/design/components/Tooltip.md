# Tooltip

Rótulo curto que aparece em hover e em foco de teclado; o consumidor fornece o texto (e o atalho, se houver).

- Fundo invertido (`viz-tooltip-bg`/`viz-tooltip-text`), 11 px, até 240 px de largura.
- Obrigatório em todo IconButton e em todo controle desabilitado (explica o motivo).
- Tooltip de dados no gráfico usa o mesmo componente, com numerais tabulares.
