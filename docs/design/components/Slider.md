# Slider

Ajuste contínuo com valor editável ao lado; o consumidor fornece mínimo, máximo, passo, unidade e valor.

- Trilho de 2 px (preenchido em `accent` até o valor), alça de 12 px; o campo numérico à direita aceita digitação e setas (Shift = 10).
- Sempre acompanhado do Input numérico: o slider sozinho não é preciso o bastante para BI.
- Usos: opacidade de camada, raio de cluster e heatmap, transparência de série.
