# Checkbox

Marca opções independentes e listas de valores de filtro; o consumidor fornece rótulo e estado (marcado, desmarcado, indeterminado).

- Caixa de 14 px com área de clique de no mínimo 24 px (a linha inteira é clicável).
- Indeterminado para "Todas" quando parte dos itens está marcada.
- Para ligar/desligar uma seção inteira do Inspector, use Switch no cabeçalho da seção.
