# @biweb/dashboard-runtime

Renderização React do documento: layout renderer, widget host, controles de filtro. Usa só tokens runtime (`dash-*`, `viz-*`).

- Épico: **E2.4** (docs/architecture/32-epics-and-implementation-prompts.md)
- Depende de: `@biweb/dashboard-core`, `@biweb/layout-engine`, `@biweb/viz-sdk`, `@biweb/ui`, `@biweb/tokens`
- Regras de fronteira: `.dependency-cruiser.cjs` na raiz.

Status: esqueleto. A API pública abaixo é só o ponto de partida.
