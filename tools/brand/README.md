# tools/brand

- `assets.py <pasta-com-imgs> apps/web/public/brand`: recorta e exporta logo claro/escuro/mono, símbolo, logo empilhado, favicon e apple-touch-icon a partir dos PNGs de `design-handoff/images` (renomeados img1…img5 na ordem do nome).
- `covers.py apps/web/public/covers apps/web/public/brand/mark.png`: gera as capas 16:9 dos relatórios com a paleta da marca.

Requer Python 3 + Pillow.
